# Online Messenger

---

## 📖 О проекте

1. Проект представляет собой онлайн-мессенджер для общения.
2. Поддерживается только приём и отправка сообщений.
3. Присутствует смена темы в окне чата, смена никнейма и выход из системы.
4. UI — собственный, API и бэкенд — сторонний, с ресурса Strada.

---

## 🧭 Использование приложения (позитивный сценарий)

1. Открыть локально собранного хоста.
2. Ввести существующую почту.
3. Ввести ключ-токен в модалку **Get Code**.
4. Подтвердить ключ-токен в модалке.
5. Ввести и отправить сообщение.
6. WebSocket спустя небольшое время подтянет и отобразит ваши сообщения и чужие.

---

## 🛠 Техническая информация

1. Проект реализован при помощи JavaScript / TypeScript, HTML, CSS.
2. В проекте используется сборщик Vite.
3. В проекте используются сторонние библиотеки для работы с датами и куки.
4. Проект реализован в IDE: WebStorm.
5. Используется линтер ESLint.
6. Используются API-запросы и взаимодействие с сервером.
7. Используются cookies для хранения токена авторизации со сроком хранения.
8. Используются WebSocket.

### Техническая информация по установкам либ (необходимых библиотек) и локальному запуску:
1. Установить пакет npm install js-cookie.
2. Установить пакет npm install date-fns.
3. Установить ESlint npm init @eslint/config@latest.
4. Установить пакет npm i.
5. Установить TS npm install -g typescript.
4. Установить новый пакет Vite - npm i vite.
5. Убедится, что в index.html подключаете модуль index.js (именно как модуль).
6. Запустить, вашу сборку в режиме разработки npx vite dev (npm run dev в случае из package.json).
7. Откройте ссылку хоста в браузере, которая получилась в шаге №7 в CLI.
8. package.json
```{
   "name": "my-app",
   "version": "1.0.0",
   "scripts": {
   "dev": "vite",
   "build": "vite build",
   "preview": "vite preview"
   },
   "devDependencies": {
   "vite": "^7.3.6"
   },
   "dependencies": {
   "date-fns": "^4.4.0",
   "js-cookie": "^3.0.8"
   }
   }```
